# velardo.org

This repository publishes [velardo.org](https://velardo.org/) with GitHub Pages.

## Structure

* `index.html` is the current identity and biography page.
* `assets/images/` contains current site imagery.
* `assets/press/` preserves historical press evidence, scans and copies related to earlier work.
* `projects/` contains intentionally preserved technical experiments, prototypes and utilities.
* `myWork/` contains only legacy redirects so older URLs resolve to the current homepage.
* `content/bio.md` is a reusable long, short and compact biography source.

The current homepage is deliberately lightweight and has no local CSS or JavaScript framework dependency.

## Publishing

The site is static. Changes pushed to `master` are published through GitHub Pages using the custom domain configured in `CNAME`.

## Historical code

Code under `projects/` is retained as technical archaeology. It may use old libraries or coding patterns and should not be interpreted as current production guidance.

Third party libraries and assets retain their respective original licences. Historical press material remains attributable to its original publishers and is retained here as evidence of coverage.
